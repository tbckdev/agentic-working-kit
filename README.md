# Agentic Working Kit

Tài nguyên mở cho các workflow trên [AgenticWorking.io](https://agenticworking.io).

## 🚀 Quick Start

### Clone toàn bộ
```bash
git clone https://github.com/egany/agentic-working-kit.git
cd agentic-working-kit
```

### Hoặc tải ZIP từng workflow
- [invitation-maker.zip](https://github.com/egany/agentic-working-kit/releases/latest/download/invitation-maker.zip)
- [media-processor.zip](https://github.com/egany/agentic-working-kit/releases/latest/download/media-processor.zip)
- [excel-merge.zip](https://github.com/egany/agentic-working-kit/releases/latest/download/excel-merge.zip)

## 📁 Workflows

| Workflow                               | Mô tả                     |
| -------------------------------------- | ------------------------- |
| [invitation-maker](./invitation-maker) | Tạo thiệp mời hàng loạt   |
| [media-processor](./media-processor)   | Xử lý ảnh/video hàng loạt |
| [excel-merge](./excel-merge)           | Gộp file Excel            |
