# Sample Data

This folder contains sample files for testing the Media Processor workflow.

## Structure

```
sample-data/
├── input/          # Place product images here (JPG, PNG, WebP)
├── output/         # Processed images will be saved here
└── watermark.png   # Watermark file (PNG with transparency)
```

## Notes

- Place your product images in the `input/` folder
- Provide a `watermark.png` file with transparency
- Output folder will be created automatically
- Supported formats: JPG, JPEG, PNG, WebP, BMP, GIF
