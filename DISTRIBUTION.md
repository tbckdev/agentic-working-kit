# Distribution Links

This document contains standardized download links for Agentic Working Kit tools. These links are optimized for embedding on websites (like [AgenticWorking.io](https://agenticworking.io)) and documentation.

## 🔗 Latest Release Links (Recommended)

These links always point to the most recent version.
**Requirement:** Filenames attached to releases must remain constant (e.g., always `InvitationMaker.zip`, never `InvitationMaker_v1.zip`).

## 📦 File Types
- **Windows**: Distribution files are typically `.zip` containing the `.exe`.
- **macOS**: Distribution files are typically `.zip` containing the `.app` bundle.

> **Note:** We use `.zip` for distribution to ensure files are not blocked by browsers during download.
